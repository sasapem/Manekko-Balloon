# まねっこバルーン

風船に描かれた顔の表情を、自分の顔でマネするスマホゲーム。

1. 外カメラで風船を映す(色でどの風船か当てる)
2. 内カメラに切り替わり、その表情を自分の顔でマネする
3. AI が顔を判定。30秒で何個できるか勝負

2026年4月 Project DENT ハッカソン(第2ラウンド)で作成。
作り方のくわしい話は `まねっこバルーン_解説メモ.md` にある。

## 動かし方

```
python3 server.py        # http://localhost:8766/
python3 v2/server_v2.py  # 精度を上げた版
```

スマホのカメラを使うには HTTPS で開く必要がある。
AI 判定には環境変数 `GEMINI_API_KEY` を設定する(なくても遊べる)。
撮った写真は `captures/` に保存される(このリポジトリには入れていない)。
